# Silvoo GitHub Operations

This repository contains Silvoo organization-level GitHub materials:

- public organization profile
- default contribution and security guidance
- default pull request and issue templates
- collaborator onboarding guidance
- repository governance and safety checklists
- organization access control model

No product secrets, infrastructure identifiers, customer data, or internal credentials belong in this repository.

Start with `docs/ACCESS_CONTROL_MODEL.md` for collaborator access decisions.
