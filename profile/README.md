# Silvoo

Silvoo builds payment-control infrastructure for teams that need stronger confidence across invoices, contracts, vendors, and financial operations.

Our engineering standards are simple:

- protect customer data by default
- keep credentials out of code and history
- require review before production-impacting changes
- document operational risk clearly
- prefer deterministic systems over informal process

## Repositories

- `silvoo-payment-control` - frontend application for payment-control workflows.
- `silvoo-Backend` - backend API and shared runtime used by Payment Control.

## Security

Security issues must not be opened as public issues. Use the reporting process in `SECURITY.md` or contact the Silvoo maintainers directly.

## Collaboration

External contributors and contractors should start with:

- `CONTRIBUTING.md`
- `docs/COLLABORATOR_ONBOARDING.md`
- `docs/REPOSITORY_SAFETY_CHECKLIST.md`

Production credentials, customer data, and private environment files must never be committed.
