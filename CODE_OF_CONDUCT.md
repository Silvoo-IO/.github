# Code of Conduct

Silvoo expects professional, direct, and security-conscious collaboration.

Contributors must:

- communicate respectfully
- avoid exposing private information
- respect confidentiality and customer data boundaries
- disclose conflicts or security concerns promptly
- keep discussions focused on verifiable facts and product outcomes

Unacceptable behavior includes harassment, credential mishandling, unauthorized data access, and intentionally bypassing review or security controls.

Maintainers may restrict access for behavior that creates operational, legal, security, or reputational risk.
